# 全国 3D 流量地图

入口：区域分布（`#/region`）。

## 交互

- 全国真实高程地形，城市流量以独立标记表示；拖动旋转，滚轮或按钮缩放。
- 点击城市标签、立柱或右侧城市列表，镜头在约 1.45 秒内推进到该城市，突出其真实行政区轮廓。
- 城市详情提供流量、用户数、带宽加权利用率、5G 占比和预警 / 拥塞小区数量。
- 下方展示最新 7 日负载趋势、4G / 5G 流量结构与 TOP 5 小区流量；点击条形可打开原有小区详情。
- 城市搜索、城市切换、全国返回、时间范围、指标切换与大区筛选可联动使用。
- 连续切换城市时，镜头不重播聚焦动画，而是从当前位姿实时演算平滑移动到新城市；拖动会接管镜头。系统偏好减少动画时立即定位。
- 地图边界均为本地资源；3D 初始化失败时仍可通过城市列表查看数据。

## 地理白模

地形顶点来自 Mapzen Terrain Tiles 的真实高程（SRTM / GMTED2010 / ETOPO1 等公开地形源），不是行政区统一挤出、随机噪声或流量柱组成的山体。

- 全国表面使用 zoom 6 的原始 DEM，经过采样和行政区裁切后形成约 57 万顶点的地形网格。
- 60 个城市分别预生成周边地形，使用 zoom 9 的原始 DEM。按需加载，每次最多缓存 4 座城市。
- 国家与城市边界来自原有 DataV 数据，并贴合采样地形。几何采用同一 Web Mercator 投影，模型中的城市坐标沿用原始中心点。
- 材质为无彩色哑光白模，阴影与法线表现山脊、峡谷、高原及盆地；业务指标只改变城市标记和排名，不改变地形高程。
- 全国视角垂直高程夸张 **24 倍**、城市近景 **6 倍**，页面明确标注。按 36°N 的投影比例将米转换为模型单位；这属于全国尺度的地形可视化，不是测绘用等比例模型。
- 聚焦城市后全国白模不再整体隐藏：以低透明度（约 0.5）的淡灰虚化层保留周边地形语境，城市周边精细网格保持实体白模；标记与边界的高程采样出界时回退全国 DEM，贴合可见地形。
- 全国与城市模型均为静态离线资源。每座城市的地形来自真实周边区域，未加入虚构建筑、道路或基站。
- 解码、投影、网格裁切脚本：`web/tools/prepare-terrain.py`。生成网格与配套高程采样栅格到 `web/public/geo/terrain/`，源瓦片缓存在被忽略的 `web/.cache/terrain-tiles/`。

来源与数据精度说明：[AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)、[Mapzen 数据格式](https://github.com/tilezen/joerd/blob/master/docs/formats.md)。DEM 来源、瓦片 zoom、渲染网格精度是不同概念：近景为高程地形模型，不代表街道或建筑精度。

模型不会随流量、人均或用户数改变山体；仅在全国 / 城市之间切换明确标注的高程夸张。

## 统计口径

白模地形保持独立于业务指标；城市数据由现有 `api.cells` 接口返回的重点小区聚合，不按比例编造全市流量。

| 指标 | 口径 |
| --- | --- |
| 城市流量 | 该城市重点小区的 `traffic` 之和，跟随今日 / 7 天 / 30 天 |
| 用户数 | 小区 `users` 之和，未经跨小区去重，不作为全市独立活跃用户 |
| 人均 | 重点小区流量 / 小区用户数之和 |
| 利用率 | 使用 `bandwidthMbps` 加权的当前时间范围小区 `util` |
| 5G 占比 | 5G 重点小区流量 / 全部重点小区流量 |
| 近 7 日负载 | 对小区 `trend` 按带宽加权；日期从元数据 `dateEnd` 倒推 |
| 增速 | 暂无独立城市同比；明确显示为「所在省同比」，不伪装为城市增速 |

当前数据仍是原项目的模拟数据，覆盖 60 个城市、420 个重点小区。

## 实现与验证

- `TrafficExplorer.vue`：城市列表、指标与详情图表。
- `TrafficMap3D.vue`：统一投影、几何、镜头、点选、标签避让与资源释放。
- `lib/cityTraffic.ts`：城市聚合。
- `public/geo/cities.json`：DataV 城市边界及中心坐标，更新脚本为 `tools/prepare-city-geo.mjs`。
- `pnpm typecheck`、`pnpm build`：类型与构建检查。
- `node tools/map-verify.mjs`：城市点击、动画、连续切换、数据核对、时间筛选、搜索、返回、详情抽屉、减少动画、响应式、重新挂载、离线切换。截图保存在忽略的 `docs/map-check/`。

Windows 当前保留了 5141–5240 端口段；本次预览使用 `pnpm exec vite --host 127.0.0.1 --port 5400`。验收时设置 `SHOT_BASE=http://127.0.0.1:5400/`，或按实际预览地址设置。
