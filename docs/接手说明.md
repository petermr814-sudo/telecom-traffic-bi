# 接手说明

这份文档写给下一个改这个前端的人。先读它，再动代码。

## 1. 项目是什么

《分布式系统原理与实践》大作业题目 9「电信运营商用户流量分析」的**纯前端 BI 看板**。

- 技术栈：Vue 3 + TypeScript + Vite + ECharts
- 不需要 UI 组件库，样式和组件都是项目内自己写的
- 六个页面：总览、时段、区域、资源、实时、数据任务
- 当前数据：`web/public/data/dataset.json`（模拟数据，固定种子）
- 后端：未知/未接，接口契约在 [接口契约-v1.md](接口契约-v1.md)

## 4. 数据流

```text
页面 (views/*.vue)
  → useAsync(api.xxx, deps)
    → api/client.ts
      → mock 模式：api/mock.ts 读 public/data/dataset.json
      → api 模式：fetch /api/v1/*
```

页面只认 `api/types.ts` 的模型。后端字段不一样时，**只改 `api/client.ts` 或加 adapter，不要改页面**。

## 5. 图表层的三个硬约定（踩过坑）

### 5.1 ECharts 实例必须用 `shallowRef`

```ts
// BaseChart.vue
const chart = shallowRef<echarts.ECharts | null>(null)
```

不要改成 `ref`。Vue 的深度响应式代理会破坏 ECharts 内部 `this` 和坐标系统，表现为：tooltip 不显示、`resize()` 报 `Cannot read properties of undefined (reading 'type')`、地图/折线不刷新。

### 5.2 必须监听 option 变化

```ts
watch(() => props.option, render)
```

`BaseChart` 只在 `onMounted` 里 `setOption` 一次是不够的：父组件筛选项变化时 `option` 是新对象，但没有 watch 就不会重绘。

### 5.3 系列数量/类型变化必须 `replaceMerge`

```vue
<!-- 会增删系列或切换 line/bar 的图 -->
<BaseChart :option="trendOption" :replace-merge="['series']" />
<!-- 热力图/地图还要重建 visualMap -->
<BaseChart :option="heatOption" :replace-merge="['series', 'visualMap']" />
```

`setOption(option, { notMerge: false })` 只会合并，删不掉旧系列、旧 markLine。柱状图切不过去、日均线去不掉、对比关了还在，都是这个原因。

### 5.4 初始化的 320ms 延迟

```ts
onMounted(() => window.setTimeout(waitAndInit, 320))
```

页面切换有 0.2s 的 transform 过渡，过渡期间初始化会让 tooltip 容器定位异常。不要随手删掉这个延迟；删了要重新跑 `tools/fix-verify.mjs`。

## 6. 全局状态

`stores/ui.ts`：

- `range`：`today | 7d | 30d`
- `region`：`all | 华北 | ...`
- `compare`：是否显示上期
- `tick`：刷新计数器，所有 `useAsync` 的依赖里都有它
- `settings`：预警/拥塞阈值、自动刷新，存 `localStorage`

顶栏控件改 `ui.xxx`，页面通过 `useAsync` 的 deps 自动重新请求。

## 7. 新增一个页面

1. `views/Xxx.vue` 写页面。
2. `router.ts` 加路由和 `meta`（`title`/`subtitle`/`group`）。
3. `AppShell.vue` 的 `nav` 数组加菜单项。
4. 需要顶栏筛选就在 `meta` 里给 `compareable: true`；纯展示页给 `hideFilters: true` 和 `modeLabel`。

## 8. 接真实后端

1. 按 [接口契约-v1.md](接口契约-v1.md) 实现 9 个 GET。
2. `web/.env.local`：

```bash
VITE_DATA_MODE=api
VITE_API_BASE=http://192.168.10.101:8080
```

3. 重启 `pnpm dev`。开发环境 `/api` 会代理到 `VITE_API_BASE`，后端不用配 CORS。
4. 侧栏底部文案会从「Mock 演示数据」变成「真实接口」。

实时页目前是前端定时器模拟；接 SSE 时改 `views/Realtime.vue` 的 `onMounted`，格式见契约第 5 节。告警确认/作业重跑目前只在前端生效，需要持久化就加 POST 接口。

## 10. 已知限制

- 数据是模拟的，不是 Hadoop 集群真实产出；换真实数据只需改 `dataset.json` 或接 API。
- 未做登录/权限。
- 告警确认、作业重跑未持久化。
- 实时页 SSE 未接线，当前为模拟流。
- 地图底图来自阿里 DataV，已本地化到 `public/geo/china.json`。
- 封面学号、姓名、班级留空。
