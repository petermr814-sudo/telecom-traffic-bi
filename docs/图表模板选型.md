# 图表模板选型与替换

已读取用户提供的 `lieflat-charts/templates/` 下全部 **50 个 HTML 文件**的样式和图形清单，包含 7 个基础展示文件、18 个彩色变体、24 份中英文报告及 1 个报告目录。各文件的标题、体积、样式长度与 SHA-256 见 [完整读取清单](chart-template-inventory.json)。

选型按数据形状、读者要回答的问题、卡片宽度和现有交互进行。保留应用导航，时段页按后续要求改为“整周主体、日期详情”。图形依据模板几何与视觉编码适配 Vue / ECharts；没有引入模板 CDN、示例数据或独立报告页面。颜色沿用当前蓝阶，告警状态继续使用红色、橙色。

## 时段页的阅读与交互

默认只展示整周热力图。左侧七个日期从新到旧排列，点击日期后在下方展开当天三张统计卡片、小时分布和时段构成；24 小时明细再按需展开。点击圆点也会选中相应日期与小时。

当天指标、时段构成、柱线图全部从选中日期的同一组 24 小时读数计算。存在前一天数据时可对比，最早一天不生成虚构对比。日均线默认关闭；开启时只画参考线，具体均值放在图下注明。顶部移除与固定整周窗口无关的时间范围按钮，保留区域筛选。

未选日期时导出 7×24 条读数，选日期后导出当天 24 条。热力日期来自数据元信息的结束日期。

## 未采用的主要类别

- Lupi 扇形、径向汇聚、网络场：现有统计数据没有逐实体关联和足够的关系记录；强行使用会降低比较效率。
- 箱线、提琴、脊线：会隐藏小区明细；当前直方图与分组点图更便于定位具体小区。
- 漏斗、瀑布、桑基：当前链路各阶段指标单位不同，也没有完整的阶段转化量或路径流量，不能构造这些图需要的数据。
- OHLC、堆叠时间河流、竞速排名：没有相应的开高低收、分系列时间数据或排名历史。
- 报告 R01–R12：已比较整页排版，但当前是交互分析应用；保留应用导航、筛选和详情流程，采用合适的图形槽位。

## 数值与交互约定

- 百分比点阵以最大余数法分配整数点，合计 100 点；旁边展示实际占比，避免把整数点数当成精确百分比。
- 圆点热力图的半径按数值平方根缩放，使面积对应流量；百分比模式逐日分母，单日合计 100%。
- 直方图使用 `[下界, 上界)`，最后一箱包含 100%；中位数来自原始小区值。
- 点图不抽样，纵向错开由小区编号确定，刷新不随意改变位置。
- 排名刻度以字节为单位，分区刻度以消息份额为单位，所有近似与余量均在图下注明。
